# Employee Wellness Desktop Application

This application sends a desktop notification and plays a text-to-speech reminder every 2 hours to encourage healthy hydration habits for employees.

## Features
- Desktop notification every 2 hours
- Text-to-speech reminder using Windows voice
- Customizable notification icon

## Requirements
- Python 3.x
- plyer
- pywin32

Install dependencies:
```
pip install -r requirement.txt
```

## Usage
Run the script:
```
python main.py
```
The application will run continuously, sending reminders every 2 hours.

## Note
- The notification icon path can be customized in the script.
- This application is designed for Windows systems.
